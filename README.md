# Эмулятор командной строки ОС

## Описание
Программа на Python имитирует работу командной строки операционной системы.

## Поддерживаемые команды
- `ls` — вывод содержимого VFS.
- `cd` — переход в каталог (пока заглушка).
- `exit` — завершение программы.
- `vfs-info` — вывод имени файла VFS и его SHA-256.

## Запуск
Для текущей версии нужны Python и библиотека pandas.

```bash
python3 src/main.py
```

## Пример использования
```text
user@MacBook:~$ ls
user@MacBook:~$ vfs-info
```

Примечание: пока программа обрабатывает одну команду за запуск. Для работы нужен файл VFS по пути, указанному в исходном коде.

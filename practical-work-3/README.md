
# Практическая работа №3. Ассемблер и интерпретатор виртуальной машины

**Вариант:** 21

## Этап 1. Ассемблер

Ассемблер преобразует программу на учебном языке ассемблера в промежуточное представление (IR).

### Поддерживаемые команды

| Команда | Формат | Назначение |
|---|---|---|
| `load_const` | `load_const rB, C` | Загрузка константы C в регистр B |
| `read` | `read rB, rC` | Чтение значения из памяти |
| `write` | `write rB, rC` | Запись значения в память |
| `abs` | `abs rB, C, rD` | Вычисление абсолютного значения |

### Правила языка

- Регистры записываются в формате `r0`–`r31`.
- Числа задаются в десятичном формате или с префиксами `0x`, `0b`.
- Команда `load_const` поддерживает положительные и отрицательные 28-битные числа.
- Операнды разделяются запятыми.
- Комментарии начинаются с символа `;`.
- Пустые строки игнорируются.

### Запуск

```bash
python3 -m src.assembler examples/stage1.asm output.bin --test
```

## Этап 2. Преобразование IR в машинный код

Ассемблер преобразует промежуточное представление в машинный код виртуальной машины.

Каждая инструкция занимает 5 байт. Поля инструкции размещаются в соответствии со спецификацией варианта 21.

Полученный машинный код записывается в бинарный файл.

В тестовом режиме (`--test`) выводятся:
- промежуточное представление инструкций;
- машинный код в шестнадцатеричном формате;
- размер машинного кода в байтах.

### Проверка бинарного файла

```bash
xxd -g 1 output.bin
```

## Этап 3. Интерпретатор виртуальной машины

Интерпретатор загружает бинарный файл, декодирует инструкции и выполняет их.

Поддерживаются команды:
- `load_const` — загрузка константы в регистр;
- `read` — чтение значения из памяти;
- `write` — запись значения в память.

Программа использует общую память для инструкций и данных. После выполнения интерпретатор сохраняет выбранный диапазон памяти в CSV-файл.

### Запуск интерпретатора

```bash
python3 -m src.main stage3.bin memory.csv --start 0 --end 85
```

Параметры:
- `stage3.bin` — входной бинарный файл;
- `memory.csv` — файл дампа памяти;
- `--start` — начальный адрес дампа;
- `--end` — конечный адрес дампа.

### Проверка копирования данных

Пример программы находится в `examples/stage3.asm`. Она копирует три значения из памяти по адресам `0`, `1`, `2` в ячейки `80`, `81`, `82`.

## Этап 4. Команда abs

Реализована команда `abs`, которая вычисляет абсолютное значение числа из регистра B и записывает результат в память по адресу, вычисляемому как сумма значения регистра D и смещения C.

### Пример

Программа находится в `examples/stage4.asm`.

```asm
load_const r23, -15
load_const r29, 100
abs r23, 10, r29
```

Команда `abs` записывает результат `15` по адресу `110` (100 + 10).

### Запуск примера

```bash
python3 -m src.assembler examples/stage4.asm stage4.bin
python3 -m src.main stage4.bin stage4.csv --start 100 --end 110
cat stage4.csv
```

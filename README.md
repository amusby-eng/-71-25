# Эмулятор командной строки ОС

## Описание

Программа написана на языке Python и представляет собой простой эмулятор командной строки операционной системы. Программа обрабатывает команды пользователя и работает с виртуальной файловой системой (VFS), представленной в формате CSV.

## Команды

- `ls` — вывод содержимого файла VFS.
- `cd` — имитация перехода в указанную папку.
- `exit` — завершение программы.
- `vfs-info` — вывод пути к файлу VFS и его хеша SHA-256.

## Структура проекта

- `src/main.py` — основной код программы.
- `tests/test_main.py` — тестирование программы.
- `examples/vfs.csv` — файл виртуальной файловой системы.
- `run.sh` — скрипт запуска программы.
- `.gitignore` — исключение ненужных файлов из Git.
- `README.md` — описание проекта.

## Запуск программы

Для работы необходим Python 3 и библиотека pandas.

Установка библиотеки:

```bash
python3 -m pip install pandas
```

Запуск программы:

```bash
python3 src/main.py
```

Перед запуском необходимо указать правильный путь к файлу VFS.

## Тестирование

Для проверки программы используется pytest.

Установка:

```bash
python3 -m pip install pytest
```

Запуск тестов:

```bash
python3 -m pytest tests
```

Тест проверяет завершение работы программы при вводе команды `exit`.

При успешном выполнении одного теста выводится:

```text
1 passed
```
